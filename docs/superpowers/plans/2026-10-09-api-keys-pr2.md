# API keys, Settings screens (PR 2 of 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settings → API keys: list your keys, create one (shown once, with Copy), revoke one in place, delete an expired one; then prove it in the real app with a script calling the API. Closes #38.

**Architecture:** A new feature folder `frontend/src/features/apiKeys/` with its queries (on the endpoints PR 1 built, already in `schema.d.ts`), one scope-wording helper shared by the list and the shown-once view, the settings page, and the create dialog. The new key lives only in the dialog's state. No backend changes.

**Tech Stack:** React + TypeScript, TanStack Query and Router, Vitest + Testing Library with `fakeServer`, Playwright (Chrome) for the in-app check.

**Spec:** `docs/superpowers/specs/2026-10-08-api-keys-design.md` §5, the frontend and in-app parts of "Tests". Design: screens 5o, 5p, 5q, 5z in `design/FolkBook.dc.html`.

## Global Constraints

- Section label "API keys", path `/settings/api-keys`, placed right after Profile & account.
- The line under the heading, verbatim: "For scripts and apps that read or write your book. Each key only sees the spaces you pick."
- Copy is verbatim from the spec: "Revoke “Birthday script”? Anything using it stops working right away.", "Revoke key", "Look up people and links", "Also add and edit people", "Include my private notes, memory aids and timeline", "Off by default. Only yours — never what other members write.", "Copy it now — you won't see it again.", "If you lose it, revoke it and make a new one.", "Copied ✓", "Never expires.", "I've saved it", "Never used", "Expired", "No spaces left", "All spaces".
- The full key is never written to the query cache, local storage or a toast; it lives in the dialog's state and is gone when the dialog closes.
- AGENTS.md frontend rules: generated API types only, queries in the feature's `queries.ts`, tokens only (no hex), `FormDialog small` for the form, `useClosing` for dialogs that animate out, no `alert()`, mobile + desktop and light + dark.

## Review Focus

1. **The key after the dialog closes:** closing (I've saved it, ✕, Esc) leaves the full key nowhere in the app's caches. Test in Task 3.
2. **Two quick submits** (double click, or Ctrl/⌘+Enter twice while the first call is out) make one key, not two. `requestSubmit()` ignores the disabled button, so the handler must check. Test in Task 3.
3. **No clipboard on a plain-HTTP server** (self-hosted on a LAN: `navigator.clipboard` is undefined outside secure origins). Copy must not throw or claim "Copied ✓"; it selects the key so it can be copied by hand. Test in Task 3.
4. **Revoking a key already revoked on another device** (404): say so in a toast and refresh the list, so the row goes away instead of sticking. Test in Task 2.
5. **A name of only spaces** passes `required` in the browser; the server's 422 "Give the key a name." shows as text in the form. Test in Task 3.

**Files:**

**Interfaces:**
- Produces (`queries.ts`):
  - `type ApiKey = components['schemas']['ApiKeyOut']`, `type CreatedApiKey = components['schemas']['CreatedApiKeyOut']`, `type ApiKeyIn = components['schemas']['ApiKeyIn']`
  - `apiKeysQuery`: `queryOptions`, key `['api-keys']`, returns `ApiKey[]` (the page's `items`, like `invitesQuery`)
  - `createApiKey(queryClient: QueryClient, body: ApiKeyIn): Promise<CreatedApiKey>`: POST, then invalidate `apiKeysQuery` (never `setQueryData` with the response: it holds the key)
  - `revokeApiKey(queryClient: QueryClient, keyId: string): Promise<void>`: DELETE `/api/api-keys/{key_id}`, then invalidate
- Produces (`scope.ts`), all taking `Scoped = Pick<ApiKey, 'name' | 'read_only' | 'include_private' | 'limited' | 'spaces'>`:
  - `accessLabel(key): string`: `"read-only"` or `"read-write"`
  - `PRIVATE_LABEL = '+ private notes'`
  - `spacesLabel(key): string`: `"All spaces"` when not limited, `"No spaces left"` when limited with none, else the names joined with `", "` in the order the API gives
  - `scopeSummary(key): string`: `` `${name} · ${access}${include_private ? ' + private notes' : ''} · ${spaces}` ``
- Produces (`lib/dates.ts`): `formatRelativeMoment(isoMoment: string, now: Date = new Date()): string`

- **Last used:** `formatRelativeMoment(last_used_at)` or "Never used";

Revoke swaps the row's action area for the confirmation (text from Global Constraints with the key's name, **Cancel**, **Revoke key** as the danger button), with focus moved to Cancel. Delete on an expired key deletes right away: it no longer works, so there's nothing to confirm. A failed revoke or delete calls `notify({ title: "Couldn't revoke it", description: error.message })` and invalidates `apiKeysQuery`.

### Task 3: Create a key, and show it once

**Files:**
- Create: `frontend/src/features/apiKeys/CreateKeyDialog.tsx`
- Modify: `frontend/src/features/apiKeys/ApiKeysSettings.tsx` (mount it), `frontend/src/components/ui/copy-link.tsx` (extract `useCopy`)

**Interfaces:**
- Consumes: Task 1's `createApiKey`, `scopeSummary`, `type CreatedApiKey`; Task 2's `creating` state; `spacesQuery` (`features/spaces/queries`); `FormDialog`, `FormDialogFooter`, `Choice`.
- Produces: `CreateKeyDialog({ open, onClose }: { open: boolean; onClose: () => void })`; `useCopy(text: string): { copied: boolean; copy: (field?: HTMLInputElement | null) => void }` in `copy-link.tsx`, used by `CopyLink` too. On success it sets `copied`. With no clipboard, or when writing fails, it leaves `copied` false and selects `field`, so the user can copy it by hand.

One `FormDialog small` with `formId="api-key-form"`, two steps:
- **Create** (title "Create API key", submit "Create key"):
  - **Name**: `required`, `maxLength={60}`, placeholder "Obsidian sync".
  - **Scope**: `Choice look="box"` radios, Read-only / Read-write, each with its line under it. Read-only is the default.
  - **Limited to spaces**: a `Choice type="checkbox"` chip for each of `spacesQuery`'s spaces, and an **All spaces** chip. All spaces is ticked while no space is; ticking a space unticks All spaces; ticking All spaces clears the spaces; unticking the last space goes back to All spaces. So `space_ids` is the ticked ids, or `null`; the UI never sends `[]`.
  - **Private notes**: a checkbox like `ShareDialog`'s contact-details one, label and note from Global Constraints, off.
  - **Expires**: `Choice look="box"` radios `30d` "30 days", `90d` "90 days" (default), `1y` "1 year", `never` "Never".
  - A server error shows as text above the footer; `FormDialogFooter small submitLabel="Create key"`.
  - The submit handler returns early while the call is out (Review Focus 2).
- **Created** (title "Key created", submit "Done" in the phone header): the same `<form id>`, whose submit closes the dialog. It shows the two warning lines; `scopeSummary(created)`; the key in a read-only mono `Input` (`aria-label="API key"`) with a **Copy** button ("Copied ✓" once copied); "Expires {formatDay(expires_at.slice(0,10))}." or "Never expires.", then "Use it as <code>Authorization: Bearer …</code>"; and **I've saved it** (submit).
- The created key is kept in `useState` set from the mutation's `onSuccess`, and the mutation has `gcTime: 0`, so nothing outlives the dialog.
